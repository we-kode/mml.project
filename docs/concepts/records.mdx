# Records

Records are audio files uploaded by one [admin](./admins) in the admin app. 

:::info File format
Only mp3 files supported yet.
:::

Records can only be played by registered [clients](./clients) which are in the the same [group](./groups). One record can be managed in the admin app by clicking on it or multiple rceords with a long press at one of them.

## Indexing records

Records will be indexed based on the [id3 tags](https://id3.org/) of the audio file. Some tags are required, other can be left empty. The indexed information can be changed at any time in the admin app when managing records. Following tags will be captured: 

- **Required**:
  - **title** or **filename** will be used as title if title tag is empty.
  - **tracknumber**
  - As date the creation date of the file will be used by default. If you want to set your own date add one prefix in form `yymmdd_` to the filename.
- **Optional**:
  - **artist**
  - **album**
  - **genre**
  - **language**

The records will be displayed grouped by the date and tracknumber in a flat view or folder view. Records can be compressed when uploading. One [admin](./admins) can be manage the comression in the settings of admin app. If no value is entered no compression of the records will be performed.


[Clients](./clients) can filter on indexed tags.

## Records of partner instances

With [federation](./federation) records are synchronized with partner instances. The instance where a record was uploaded is its owner.

The records overview shows the synchronization state of each record with a symbol on the cover:

- **Sync arrow down:** The record was received from a partner. The owner is shown in italics below the title. Its metadata can only be changed by the owner; admins can change the groups and the lock of these records.
- **Sync arrow up:** The record was sent to at least one partner.
- **Sync problem:** Sending, updating or deleting the record at a partner failed or is retried after an error. **Synchronize** sends the record again.

The record details show the owner and when the record was received, or the partners an own record was sent to, and the problems per partner with the error and the next attempt. The filter **Synchronization** in the records overview shows the records of the selected states.

The admin app offers two additional filters in the records overview:

- **Unassigned** shows records without any group, e.g. received records which matched no incoming rule.
- **Records of instance** shows records owned by the selected instances.

Own records and folders can be sent to partners with **Synchronize** in the multi selection of the records overview or in the record details. Only records matching an outgoing rule of a partner and not sent to it yet are synchronized.
